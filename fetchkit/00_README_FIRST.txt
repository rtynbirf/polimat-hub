КОМПЛЕКТ СКАЧИВАНИЯ МОДЕЛЕЙ · POLIMAT_FETCH_KIT v1 · 2026-11-08

Что это
  Автономный комплект скачивания локальных моделей с huggingface.co.
  Внутри 4 файла: FETCH_MODELS.bat (запуск двойным кликом),
  tools\fetch_models.py (чистый stdlib: без pip, без токенов, из сети -
  только huggingface.co), SHA256SUMS.txt (контрольные суммы файлов комплекта),
  этот README.

Как запустить
  1. Распаковать ZIP целиком в любую папку. Батник и папка tools должны
     остаться рядом - проверка ругнётся, если их разлучить.
  2. Двойной клик по FETCH_MODELS.bat. Нужен Python 3
     (в установщике - галка "Add python.exe to PATH").
  3. Ждать ~900 МБ: mt = NLLB-200 (перевод, 200 языков, ~850 МБ) +
     asr-tiny = whisper-tiny (речь, ~40 МБ). Прервалось - запусти ещё раз:
     докачает с того же места. Лишние варианты декодеров не качаются -
     только то, что реально грузит плеер (encoder + merged, dtype q8).

Куда падает
  .\models\Xenova\nllb-200-distilled-600M\
  .\models\onnx-community\whisper-tiny\
  .\models\MANIFEST.sha256 - sha256 каждого файла + строки "# revision"
  с зафиксированной ревизией каждого репо HF.

Про ревизии (v2 тулзы)
  Первый прогон фиксирует текущую версию каждого репо HF; повторные прогоны
  качают строго её - копии воспроизводимы и совместимы с торрент-раздачей.
  Сменить ревизию: удалить models\MANIFEST.sha256 (фиксация заново) или
  запустить tools\fetch_models.py с --pin SHA.

Проверка целостности
  Повторный запуск батника пересчитает sha256 уже скачанных файлов.
  Отдельный файл: certutil -hashfile <файл> SHA256, сравнить с SHA256SUMS.txt
  (сам манифест не самохэшируется).

Не клади models\ в git-репозиторий: модели в git не живут (LOCAL_FIRST).
