# reports/

Папка для данных, которые копят регулярные воркфлоу polimat-hub.

- `quota-history.jsonl` — история измерений квоты: по одной JSON-строке на прогон с полями `date` (YYYY-MM-DD), `pool_bytes` (байты пула 500 МБ: артефакты + Packages) и `repos` (число репозиториев в замере). Создаёт и дополняет `tools/quota_predictor.py` (джоба `predictor` в `.github/workflows/quota-hygiene.yml`); замер за уже существующую дату заменяет точку, а не дублирует. Джоба работает под `contents: read`: обновлённая история печатается в шаг-сводку прогона, а накопление между прогонами потребует возвращать файл в репо (коммит-бэк — отдельное решение Хозяина).
- `pool.json` — разовый срез трёх пулов от `tools/three_pool_hygiene.py` внутри джобы (путь задаёт флаг `--json`); в репо не хранится.

По последним ≤14 точкам истории `tools/quota_predictor.py` строит линейный склон и выдаёт «дней до 500 МБ» с вердиктом: 🔴 меньше 7 дней, 🟡 7-14, 🟢 больше 14.
