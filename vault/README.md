Мандат Хозяина: 2026-11-08 — «найдёшь себе место для сверок, вклинишь своё для хранения».

## Содержимое

Каждый `.bundle` — полный git-зеркало-бандл репозитория, снятый ПЕРЕД операцией слияния/удаления.
