# POLIMAT-VAULT — хранилище пломб Полимата

Автономный бэкап-архив restructuring-операций мультиагента ПОЛИМАТ на аккаунте rtynbirf.

Мандат Хозяина: 2026-11-08 — «найдёшь себе место для сверок, вклинишь своё для хранения».

## Содержимое

Каждый `.bundle` — полный git-зеркало-бандл репозитория, снятый ПЕРЕД операцией слияния/удаления.
Восстановление: `git clone bundle-X.bundle восстановленное-имя`

## Пломбы

Контрольные суммы SHA256 всех бандлов — в `MANIFEST.sha256` (культура аккаунта: пломбы на каждый артефакт).
