# СТАНДАРТ LOCAL-FIRST · ПОЛИМАТ / rtynbirf

- Версия: 1.0, 2026-11-08. Базируется на принципах Ink & Switch («Local-first software», 2019)
  и на фактически проверенном материале пакетов «пилот» и «раунд 2» внешнего агента.
- Цель: страница или приложение работает полностью на устройстве пользователя; сеть —
  опция, а не условие жизни.

## 1. Принципы

1. Данные и вычисления — на устройстве. Сервер не хранит то, что не обязан хранить.
2. Отсутствие сети — штатный сценарий, а не ошибка.
3. Каждая внешняя точка либо вычищена, либо записана в белый список с обоснованием.
4. Лестница отката честная: страница не притворяется автономной, если взяла файл с CDN.

## 2. Шрифты

- Только self-hosted woff2, разбитые на подмножества (кириллица/латиница).
- Эталон: `singulyar/fonts/` — manrope-cyrillic.woff2, manrope-latin.woff2,
  unbounded-cyrillic.woff2, unbounded-latin.woff2 + лицензия OFL.
- Google Fonts и прочие шрифтовые CDN запрещены: headless-проверка cinema показала,
  запрос к Google Fonts исчез после вендоризации.
- Для критических страниц допустим base64-инлайн шрифта в HTML (ценой веса файла).

## 3. Библиотеки (vendor)

| Требование | Проверка |
|---|---|
| Файл лежит в `vendor/` репозитория | `test -f` |
| Версия зафиксирована (имя каталога/заголовок файла/примечание) | README vendor |
| sha256 файла равен оригиналу на CDN издателя | `sha256sum` против jsdelivr/unpkg |
| SRI-атрибут в разметке соответствует файлу | `openssl dgst -sha384 -binary | base64` |
| Обновление = отдельный коммит с новой суммой | git log |

Эталоны 2026-11-08: transformers.js 3.7.5, hls.js 1.5.13, webtorrent 2.5.1 — sha256 совпал
с jsdelivr; three.js r128 — sha384 совпал с integrity из страницы (`CI3ELBVUz9XQO…WWdHu=`).
Файл, совпадающий по имени, но не по сумме, приёмку не проходит.

## 5. Модели и инференс

- transformers.js 3.7.5 из `vendor/`, флаг `allowRemoteModels=false` — huggingface.co браузером
  не запрашивается вообще.
- WASM-бэкенд vendored: ort-wasm-simd-threaded.jsep.wasm 21,6 МБ, две копии байт в байт —
  дедуплицировать в Ф4.
- Модели (NLLB-200, Whisper tiny/base/small, суммарно ~650 МБ на стартовый набор) живут в
  `./models/`, в git не кладутся. Скачивание — `tools/fetch_models.py` (stdlib, без токена,
  атомарная запись, MANIFEST.sha256) на машине Хозяина.
- Открытый дефект: скрипт тянет ветку main репо HF. Правка — pin конкретной ревизии в
  MANIFEST (Ф4).
- Поведение без модели: страница показывает распознанный оригинал, не падает (проверено).

## 6. Сеть и лестница отката

Ступени в порядке честности:

1. Локальный файл (`vendor/`, `./models/`, `fonts/`).
2. CDN той же версии (pinned) — если первой ступени нет.
3. Аварийная старая версия.

Страница сообщает, какая ступень сработала (лог в консоль или бейдж). Молчаливый откат
к CDN считается дефектом. Эталон: ЛАДОМ_31 — первая «дверь» уже на своём vendor +
`./models`, CDN оставлен запасным до появления моделей.

## 7. Сервис-воркер и офлайн-тест

- Предкэш критических ресурсов в sw.js; у singulyar свой воркер (sw15.js).
- Приёмочный тест: DevTools → Network → Offline → перезагрузка страницы → приложение
  работает; вкладка Network при онлайн-режиме показывает 0 внешних запросов, кроме белого
  списка. Счётчик запросов — в отчёт фазы, не на словах.

## 8. P2P

- WebTorrent: имя раздачи подтягивает сам клиент, itorrents.org удалён.
- WebRTC: режим «безСерверов» уже есть; STUN/TURN/трекер/nostr-релей собственные — отдельная
  работа (Ф5), до её завершения безСерверов — штатный режим.
- Локальные бандлы trystero-nostr уже в `БИБЛИОТЕКИ/` singulyar.

## 9. Анти-паттерны

- Горячая ссылка на картинку/шрифт чужого сайта без записи в белом списке.
- CDN без pinned версии и без суммы «потому что так проще».
- Модели, докачиваемые браузером на лету с HF.
- `__pycache__`, черновики и машинные пути (`/home/чужой/`) в поставке.
- Числа вроде «26 запросов», полученные счётом строк кода, вместо измерения в DevTools.
