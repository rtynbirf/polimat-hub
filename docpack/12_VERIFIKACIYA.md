# ПРОТОКОЛ ВЕРИФИКАЦИИ · ПОЛИМАТ / rtynbirf

- Версия: 1.0, 2026-11-08. Правило пакета: утверждение без машинного вывода не принимается.

## 1. Принцип независимости

Своё о своём не верифицируется своим же инструментом. Разрешённые каналы:

1. Другой инструмент (встроенный хэшер против самописного счётчика).
2. Другой носитель (live-API против локального бандла против офлайн-архива).
3. Другой агент (кросс-чек, как сделано 2026-11-08 для пакетов пилот/раунд 2).

Расхождение каналов — не «погрешность», а задача в журнал.

## 2. Базовые проверки

### 2.1 git-sha1 блоба (проверка содержимого файла в git)

```bash
SIZE=$(stat -c %s файл); printf '%d\0' "$SIZE" | cat - файл | sha1sum
# ожидание: совпадение с git rev-parse/ls-tree для этого blob
```

Эталон: части RUVSON_QUANTUM_v5; part1 и part5 перепроверены локально 2026-11-08
после ревокации токена — cda1c72e… и 11da60f5… совпали.

### 2.2 SRI-атрибут

```bash
openssl dgst -sha384 -binary vendor/three.min.js | openssl base64 -A
# ожидание: совпадение с integrity в разметке страницы
```

Эталон: three.js r128, sha384-CI3ELBVUz9XQO…WWdHu= — совпал.

### 2.3 Поставка против оригинала CDN (цепочка поставок)

```bash
sha256sum vendor/transformers.min.js
curl -fsSL https://cdn.jsdelivr.net/npm/@huggingface/transformers@3.7.5/dist/transformers.min.js | sha256sum
# ожидание: равенство
```

Эталоны: transformers.js 3.7.5, hls.js 1.5.13, webtorrent 2.5.1 — равенство подтверждено.

### 2.4 Пломба против live (tree-хэш)

```bash
git rev-parse <коммит>:<путь>            # в клоне из пломбы
git rev-parse origin/main:<путь>         # в live-клоне
# ожидание: совпадение хэшей дерева
```

Эталон: rumu main b21e823… — совпало; ветка membrane-2026-11-05 — НЕ обнаружена (расхождение
записано, Ф3).

### 2.5 Восстановление бандла

```bash
git clone vault/bundle-rumu.bundle /tmp/check-rumu && git -C /tmp/check-rumu fsck
```

### 2.6 Офлайн-тест и счётчик внешних запросов

Headless-браузер, локальный сервер: Network → Offline → перезагрузка; затем онлайн — подсчёт
запросов вне белого списка. Вывод — число, попавшее в отчёт; строка кода счётом запросов
не считается.

### 2.7 Скан секретов

```bash
rg -n 'ghp_[A-Za-z0-9]{36}|github_pat_[A-Za-z0-9_]{20,}' <дерево/пакет>
```

Самопроверка этого пакета: 0 вхождений (см. `00_README_FIRST.txt`, строка «Самопроверка»).
