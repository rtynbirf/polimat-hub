## Механика аудита — уроки для гейта

1. **Кириллические имена воркфлоу** (`singulyar/такт_гейт.yml`): сканеры, тянущие `download_url` без `urllib.parse.quote`, молча теряют файл (ascii-кодировка URL). Внешним проверяющим: квотить URL либо читать через contents API (base64).
2. **Ground-truth подсчёт** через git/trees API (169) сошёлся с contents API и живым свипом. Промежуточное расхождение 167↔169 в ходе аудита объяснилось параллельной посадкой двух wave6-гейтов в repo-doctrine (23:43/23:47 UTC 08.11) — не потерей сканера.
3. Гейт, который нашёл «нарушения» в собственном файле, должен уметь различать **триггер** и **упоминание** — иначе честный гейт краснит сам себя (урок прогонов 08.11, зашит в `tools/pull_request_target_sweep.py` selftest).
