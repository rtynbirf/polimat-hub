## I. МИРОВЫЕ ТРЕНДЫ 2025–2026, С КОТОРЫМИ СВЕРЯЛИСЬ

1. **Переписывание истории зрело**: `git filter-repo` даёт `--analyze` (отчёты о самых жирных путях), `--strip-blobs-bigger-than`, а место на GitHub освобождается по своему GC-расписанию — самый быстрый путь вернуть размер обратно — тикет в support [1].
2. **Экономика тяжёлых файлов GitHub**: обычный файл ≤100 МБ (жёстко), LFS-объект 2–5 ГБ по тарифу + квоты трафика; Releases не входят в git-квоту — паттерн «код в git, медиа в Releases» стал стандартом [2].
3. **Сохранность кода как сервис**: Software Heritage Save Code Now имеет вебхуки, браузерное расширение и рекомендует README+LICENSE+SPDX+`codemeta.json` перед сохранением; есть bulk-эндпоинт `/api/1/origin/save/bulk/` для пакетных запросов [3][4].
4. **On-device AI в браузере**: Transformers.js v3 + WebGPU (ускорение 3–20× против WASM), детект фич (shader-f16) и fallback на WASM; модели кэшируются по-origin в браузере — два сайта = две копии модели [5][6].
5. **Offline-first как UX-контракт**: тяжёлые модели — явный шаг скачивания («informed opt-in»), кэш-стратегии service worker, запрос постоянного хранилища, чтобы браузер не выселил модели [5][7].
6. **Флейки не ретраят, а карантинят**: мировой стандарт — quarantine с владельцем и сроком, метрики (доля красных, время простоя пайплайна); слепые ретраи маскируют баги [8][9].
7. **Dependabot без шума**: grouped updates (minor+patch пачкой, major отдельно) + cooldown замедляют каденс; security-фиксы всегда мгновенно и вне групп [10][11].
8. **CodeQL default setup управляется API**: у REST есть «Get/Update a code scanning default setup configuration» — включение дефолтного CodeQL программно возможно при правильном скоупе токена [12].
9. **GitHub завёл Agents API**: REST-разделы «Agent tasks» (list/start/get) и чейнджлог «Start Copilot cloud agent tasks via the REST API» (2026-05) — задачи агентам теперь можно выдавать и читать через API, прямо из файла-карты [13][14].
10. **Своя P2P-инфраструктура подешевела**: coturn на VPS ~$20/мес дешевле облачных TURN на 70–90% (обязательны time-limited HMAC-креды, TLS 5349, запрет RFC1918, квоты; трафик удваивается) [15]; nostr-релей серверлес на Cloudflare Workers на 75–90% дешевле классики [16], персональный релей от €2/мес [17]; WebTorrent гибрид умеет web-seed (браузерный пир + обычные HTTP-сиды) [18].
11. **Lean 4 взорвался**: AlphaProof, Seed-Prover, Gauss (теорема о простых за 3 недели против 18 месяцев у людей); появились Comparator (независимая перепроверка экспортированных доказательств), Lean Eval (лидерборд), Palomar (реестр Lean-верифицированной математики), паттерн «AI-автор + adversarial review против открытых рубрик» [19][20].
12. **Синхрон текстов стандартизован**: LRC — де-факто стандарт карaoke-текста [21], есть драфт LRCv2 (перевод, певцы, семантика, аккорды) [22] и зрелые конвертеры LRC↔TTML (последний — стандарт word-level синхрона) [23].
13. **Экспорт чатов**: де-факто практикa — JSONL с нормализованными ролями (user/assistant/system) + метаданными диалога, параллельный Markdown-дамп для чтения [24].
14. **REUSE/SPDX автоматизирован**: `LICENSES/` каталог + SPDX-хедеры + `reuse lint` в CI — это же официальная рекомендация SWH по подготовке репо к сохранению [3][25].
15. **Профили и витрины динамические**: профиль-README, обновляемый Actions-кроном из живого API, бейджи и статс-карты — числа не протухают [26].

### II.1 P0 · Тяжёлое/безопасность

**P0-1 · git filter-repo ruvson-lyrics (446,7 МБ в истории)**
- Мир: `filter-repo --analyze` даёт ранжированный отчёт о жирных путях ДО переписи; после rewrite — `reflog expire --expire=now --all` + `gc --prune=now --aggressive`; на GitHub место падает по своему GC — тикет в support ускоряет [1].
- [О] перед rewrite: `git filter-repo --analyze` на зеркале → `path-all-sizes.txt` в `audit/` — свидетельство ДО.
- [Э] «тройной шлюз»: (1) пломба-бандл + SHA256; (2) rewrite по 5 sha1 → свежий клон → fsck → tree-хэши канона; (3) тикет GitHub на GC + контроль size-API через 24/48/72 ч, график деградации размера — в журнал. Пункт закрыт не «я переписал», а «размер физически ушёл».
- [С] `tools/rewrite_with_seal.py`: пломба→rewrite→fsck→отчёт одной командой, отказ без `--owner-confirmed` (протокол docpack/07 §4 уже требует команду Хозяина — скрипт делает требование неисполнимым).

**P0-2 · ADR-005 singulyar (1547 МБ мелких файлов)**
- Мир: лимит файла 100 МБ жёсткий; LFS — квоты трафика; Releases бесплатны от git-квоты — «медиа → Releases» уже отработано у нас на КУБ-2026 [2].
- [С] «три сундука»: git (код + мелкая статика) / Releases (медиа частями, как КУБ-2026) / fetchkit-манифест (pinned-скачивание у потребителя). Обобщение fetchkit: `tools/fetch_media.py` — манифест + SHA256 + pin ревизии; тот же контракт, что у моделей, теперь для любых медиа.
- [У] верификатору — отдельный warn «blob >50 МБ в дереве» (сейчас ловим только вес репо).
- [Э] в README singulyar — «КАК-КЛОНИРОВАТЬ-ЛЕГКО.md»: `git clone --filter=blob:none` + `sparse-checkout set code/` (partial clone — мировой способ ходить в монолиты) [27].
- [О] ort-wasm дедуп (2×21,6 МБ) — первый кандидат, экономия видна сразу.

**P0-3 · Пломбы расхождений (windows-chronicle после-слияния, rumu после 53e1fa1)**

### Универсальные инварианты (для всего роя, тираж на 41)

- **Свидетельство-как-код**: каждое «сделано» = JSON-файл в `audit/` с полями (rule, kind, value, captured_at).
- **Пин-ревизий везде**: HF-модели (уже), бандлы (SHA в имени), линтеры, upstream-синх — воспроизводимость как валюта.
- **Один командный вход агента**: `agent_checkin.py` — меньше шагов, меньше забытых сверок.
- **Критерии = скрипты**: `criteria_check.py` OK/FAIL по фазам — приёмка машиной.
- **Пломба-мембрана**: имя пломбы несёт SHA своего факта.
- **Карта правится, а не реальность**: расхождение карты с API — правка карты, никогда наоборот.
- **Блокировка = результат**: blocked-запись равноправна done в своде.
