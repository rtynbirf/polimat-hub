# AGENTS-CANON · скелет AGENTS.md для репо роя (П-73, polimat-hub#97)

Каждое репо роя несёт `AGENTS.md` по этому канону: шесть секций, жёсткая граница Always / Ask first / Never. Ниже — скелет с примерами формулировок; порядок секций не менять, пункты наполнять по факту конкретного репо.

## 1. Что это
- Одной-двумя строками: назначение репо и чего здесь НЕТ.
- Пример: «Инструменты реестра роя: свипы, гейты CI, инвентари. Продуктовых данных и секретов нет».

## 2. Как собрать/запустить
- Минимальный путь от клона до работающего состояния, только реальные команды.
- Пример: «python3 tools/<имя>.py --selftest — самопроверка без сети; живой прогон требует токена в GITHUB_TOKEN».

## 3. Как проверять
- Что считается зелёным: самопроверки, гейты, воркфлоу.
- Пример: «После изменения — selftest изменённого скрипта и зелёный прогон соответствующего workflow; иначе изменение не считается принятым».

## 4. Границы: Always / Ask first / Never
- Always (всегда): «Always: пиновать Actions только на проверенные SHA роя; Always: честные поля truncated/error в отчётах».
- Ask first (сначала спроси): «Ask first: массовые операции по всем репо, удаление артефактов, новые внешние зависимости».
- Never (никогда): «Never: не ходить в сеть из самопроверок; Never: не коммитить токены; Never: не переписывать историю без явной команды Хозяина».

## 5. Артефакты и приёмки
- Какие файлы/отчёты считаются результатом и где лежат.
- Пример: «Артефакт — JSON-отчёт свипа и markdown-дайджест в step summary; приёмка — SELFTEST OK плюс зелёный гейт».

## 6. Контакты роя / ссылки
- Где пульс и договор роя: PULSE и llms.txt репо-хаба polimat-hub.
- Пример: «Пульс роя — PULSE.md в polimat-hub; машинный контракт — llms.txt; вопросы — в issue полимата».

---

Мембрана машиноисполняема: `tools/membrane_lint.py` проверяет наличие трёх файлов, маркер запретов в AGENTS.md и упоминания AGENTS.md и PULSE в llms.txt (вердикты ✅/🟡/⬜, гейт exit 1 на ⬜); расписан в `.github/workflows/membrane-lint.yml` — воскресенье 05:00 UTC. Репо без AGENTS.md по этому канону линт честно красит — это и есть дефицит, который закрывает следующая волна.
