# POLIMAT-HUB · место сверок мультиагента

> «Найдёшь себе место для сверок, вклинишь своё для хранения» — мандат Хозяина, 2026-11-08.

ПОЛИМАТ — мультиагент-архитектор аккаунта `rtynbirf`. Этот репозиторий — его рабочее место:
сверки, пломбы, журнал операций, архитектура и инструменты на Python.

## Принципы (унаследованы от конституции аккаунта)

1. **Ничего не удалять без пломбы.** Каждый артефакт перед операцией — git-бандл + SHA256 в `polimat-vault`.
2. **Проверяй строкой, не смыслом.** Каждый статус подтверждается машинным выводом API, а не обещанием.
3. **UNKNOWN ≠ FALSE.** Непроверяемое помечается как непроверяемое.
4. **HYPOTHESIS → TASK GRAPH → EVIDENCE → ATTACK → UPDATE.** Цикл любой реорганизации.

## Структура

| Путь | Что это |
|---|---|
| `ARCHITECTURE.md` | Целевая архитектура репозиториев аккаунта: кластеры, канон, правила |
| `RESTRUCTURE-LOG.md` | Журнал операций реструктуризации с машинными свидетельствами |
| `tools/repo_inventory.py` | Полная опись аккаунта: API → JSON/CSV, без памяти, только вывод |
| `tools/verify_architecture.py` | Проверка соответствия аккаунта целевой архитектуре: дубли, размеры, гигиена |
| `audit/inventory-2026-11-08.json` | Снимок-сверка аккаунта на дату мандата (41 репозиторий) |

## Запуск инструментов

```bash
export GITHUB_TOKEN="***"         # реальный токен НЕ пишется в файлы — только в переменную окружения
python3 tools/repo_inventory.py    # опись → audit/inventory-<дата>.json
python3 tools/verify_architecture.py audit/inventory-2026-11-08.json   # сверка с архитектурой
```

Инструменты используют только стандартную библиотеку Python 3.10+ — ноль зависимостей,
по этике аккаунта (stdlib-only, офлайн-пригодность).
