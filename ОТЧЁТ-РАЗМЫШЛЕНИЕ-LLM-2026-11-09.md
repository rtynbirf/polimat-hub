## Вердикт

Три хода модели: (1) свалила 5 таксономий в одну кучу, (2) поймала половину ошибки и отложила
доставку, (3) доставила через два удара пользователя. ~70% содержания хода 3 уже существовало
в виде стандартов (PROV-O, ICD 203, Admiralty 6×6, Buckland) — модель их переизобрела, не зная
оригиналов. Лучшая часть — поутверждённый контроль родословной и честный инвентарь собственного поля.

## Сверка с мировыми практиками (9 позиций)

1. Граф происхождения → **W3C PROV-DM / PROV-O (2013)**: Entity/Activity/Agent, wasDerivedFrom — переизобрёл.
2. «Эхо ≠ подтверждение» → **circular reporting**, правило двух источников, **ICD 203 (DNI, 2015)** — переизобрёл, не зная имени.
3. Раздельная оценка источника и содержания → **Admiralty Code (NATO 6×6)**: A–F × 1–6 — не знал, нужно.
4. Статусы знания (наблюдение/гипотеза/вывод…) → **ICD 203** градации уверенности + эпистемология — совпало.
5. 9 классов природы → **Buckland, «Information as Thing», JASIS 42(5), 1991** — совпало заданием.
6. Самописный «единый объект» → **PROV-O + PREMIS v3 + C2PA 2.2 + Dublin Core 15 (ISO 15836)** — NIH-синдром.
7. Первичность зависит от вопроса → **Cornell / NYU LibGuides** — верно, с цитатами.
8. 4 слоя → **DIKW (Ackoff, 1989) + data governance (DAMA-DMBOK)** — жизнеспособно.
9. Поутверждённая родословная → **claim-level provenance** (RAG-цитирование, C2PA per-asset) — сильный ход.

## Исправленная модель — одна схема вместо пяти

- **Сущности (4):** РЕФЕРЕНТ (вещь мира) · АГЕНТ (производит/проверяет) · ЗАПИСЬ (оригинал/копия/производная/эхо) · СМЫСЛ (понятие/модель/статус)
- **Действия (3):** ФИКСАЦИЯ · ПРЕОБРАЗОВАНИЕ · ПРОВЕРКА
- **Связи (6, словарь PROV-O):** originated_from · recorded_by · copied_from · derived_from · quotes/translates/summarizes · supports/contradicts
- **Оценка утверждения:** надёжность источника A–F × достоверность 1–6 (Admiralty 6×6) + статус: OBSERVATION / MEASUREMENT / SOURCE-CLAIM / HYPOTHESIS / INFERENCE / MODEL-OUTPUT / OPINION / NORM / UNKNOWN
- **Правило №1:** независимость считают по линиям наблюдения, а не по числу копий — и на уровне каждого утверждения, а не документа
- **Гигиена процесса:** MECE-проверка · стабильные ID + diff · доставка вместо отсрочки · сначала стандарты, потом свои построения
